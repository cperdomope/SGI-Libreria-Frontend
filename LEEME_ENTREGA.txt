 2. PUESTA EN MARCHA RÁPIDA (5 pasos)
---------------------------------------------------------------------

 Requisitos: Node.js 20 o superior y MySQL 8.

 PASO 1 — Crear la base de datos
   mysql -u root -p < base_datos/sgi_libreria_completo.sql

   El script crea la base "inventario_libreria" con sus 10 tablas,
   3 vistas, índices y datos de ejemplo. Los usuarios ya quedan con su
   contraseña cifrada: NO hay que ejecutar ningún paso adicional.

 PASO 2 — Configurar el backend
   cd servidor
   copy .env.example .env      (completar DB_USER, DB_PASSWORD y JWT_SECRET)
   npm install

 PASO 3 — Arrancar el backend
   npm start                   → http://localhost:3000
   (debe responder: {"estado":"OK","bd":"conectada", ...})

 PASO 4 — Configurar y arrancar el frontend (en otra terminal)
   cd cliente
   copy .env.example .env      (VITE_API_URL=http://localhost:3000/api)
   npm install
   npm run dev                 → http://localhost:5173

 PASO 5 — Iniciar sesión en http://localhost:5173
